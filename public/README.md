| File | Purpose |
| --- | --- |
| `favicon.svg` | Site favicon — Franklin Mountains ridge with the Star on the Mountain. |

`app/icon.png` is picked up automatically by Next.js as the app icon.

If you replace the OG image with a raster file, update the `images` entries in
`app/layout.tsx` to point at the new filename.
